Security checklist

Before deploying to the public internet:

  • Set ADMIN_PASSWORD as a Worker secret
  • Use strong account credentials and keep Worker secrets private
  • Enable HTTPS and secure cookies
  • Keep authentication and origin checks enabled
  • Restrict D1/R2 access and configure backups
  • Keep sensitive logic server-side
